# Changelog
All notable changes to this project are documented here. Format: [Keep a Changelog](https://keepachangelog.com/), versioning: [SemVer](https://semver.org/).

## [1.0.0] - 2026-10-24
First public release.

### Added
- PostgreSQL schema (`core`, `ops`, `reporting`), reference data, audit trigger, reporting views.
- Least-privilege roles: `guard_etl`, `guard_analyst`, `guard_backup`, `guard_monitor`.
- Idempotent ETL for three ad-network file formats, with row-level rejects, file-level quarantine and a freshness check.
- `guard` command line tool: `load`, `check`, `health`, `backup`, `restore-test`, `mask-copy`, `demo-data`, `console`.
- Read-only web console (overview, pipeline runs, rejected rows, campaigns, system status, `/healthz`).
- Encrypted (GPG AES-256), checksummed backups, weekly restore test, retention, optional Azure Blob upload.
- Health check script, Prometheus alert rules, Grafana provisioning, Docker Compose stack.
- Pseudonymised non-production copy; security test-suite for roles, masking and audit.
- Four PowerShell scripts (server health, backup rotation, DB access audit, campaign report).
- Runbook, incident drills, architecture decision records, service-level targets, legacy-takeover case study.
- GitHub Actions: lint, unit tests, end-to-end load, security tests, backup/restore, documentation site.
- End-to-end ETL tests against a throw-away database (idempotency, corrected files, EUR conversion, Windows-1250 files, failure modes, freshness check, role permissions).
- Dependabot configuration, `.gitattributes`, `.editorconfig`, `make lint` and `make check`.
- GUARD brand identity (vector logo, black-and-white console theme), a 46-second demo film and infographics generated by code (`tools/video`), Polish and English READMEs.
